# TiemposEnDiferentesLenguajes
Genera una lista de números aleatorios en los rangos de 100 a 7000 usando Python, C++, y JavaScript. Luego, mide el tiempo en milisegundos o nanosegundos que tarda en ordenar la lista utilizando diferentes algoritmos de ordenamiento como burbuja, inserción, selección, fusión y rápido.
